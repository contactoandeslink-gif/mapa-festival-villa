💡 Instrucciones para Supabase (1 minuto gratis):

  1. Crea un proyecto gratis en supabase.com.
  2. En el SQL Editor, ejecuta el script de abajo.
  3. Copia tu Project URL y anon key (Settings > API) y pégalos arriba.

⚠️ Atención: la política de "escritura pública" permite que CUALQUIER persona en internet que conozca la URL del proyecto modifique los datos del festival (precios, stock e incluso las cuentas bancarias de los puestos). Para el día del evento, protege la escritura con una Edge Function (guía en el README del repo) o revisa los datos frecuentemente.
